# Support Guidelines

Thank you for using the Binance Futures DCA Trading Bot.

---

## Technical Inquiries and Support

For questions about strategy configuration, Docker setup, and general usage:

* Documentation: Read the comprehensive instructions in the repository README.
* Discussions and Questions: Open an issue on GitHub describing your question or environment setup.
* Bug Reports: If you observe unexpected execution or calculation errors, submit a detailed report using our Bug Report template.

---

## Critical Safety Reminders

* API Key Security: Never share or commit your Binance API secret key.
* IP Whitelisting: Always enable IP restriction on your Binance API keys within the exchange management console.
* Withdrawal Permissions: Keep withdrawal permissions disabled on your trading API keys at all times.
* Risk Disclosure: Cryptocurrency futures trading carries substantial financial risk. Test strategies thoroughly using paper trading or minimal position sizes before allocating capital.
