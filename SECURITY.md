# Security Policy

## Supported Versions

The following table lists the security support status for versions of the Binance Futures DCA Trading Bot:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0.0 | No        |

---

## Reporting a Vulnerability

KerberoSec takes the security of algorithmic trading infrastructure seriously. If you discover a security vulnerability in this project, we encourage you to report it responsibly.

### How to Report Privately

Please do not disclose vulnerabilities publicly via GitHub issues or discussions.

Instead, submit your findings privately through GitHub Security Advisories:

1. Navigate to the repository Security tab.
2. Select Advisories from the left sidebar.
3. Click the Report a vulnerability button.
4. Provide a detailed summary, severity assessment, affected components, and reproducible proof of concept.

---

## Response Targets

When a private vulnerability report is received, the maintainer will adhere to the following timelines:

* Initial acknowledgment: Within forty eight hours
* Vulnerability triage and validation: Within five business days
* Resolution and patch deployment: Prioritized based on severity

---

## CVE Assignment Policy

Because this is a public open source repository, eligible and verified vulnerabilities affecting the Binance Futures DCA Trading Bot can be assigned official CVE identifiers through GitHub as a CVE Numbering Authority.

### Researcher Credit and Attribution

Security researchers who responsibly discover, report, and verify vulnerabilities will be credited in:

* The official GitHub Security Advisory
* Published release notes
* The public CVE record distributed to MITRE and the National Vulnerability Database

We thank the security research community for helping safeguard financial trading software.
